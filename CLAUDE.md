# When in Rome — Brand Brain

This file is the shared source of truth for every agent. Read it before answering.

## What this is
When in Rome is an independent apparel label, run by one founder alongside a full-time job.
It's a business first — the only metric that matters is sell-through and real audience growth,
not the founder's personal taste. When instinct fights a proven move, defer to the data and
the written plan.

- **Name:** When in Rome
- **What we make:** adaptable, well-made basics — pieces built to work in any city, any scene,
  any season. Currently an 8-piece core capsule. Lineup shifts with what actually sells, not
  with what's fun to design.
- **Trajectory:** sell through the capsule → build a repeatable cadence → scale the audience.
- **Voice (marketing copy only):** confident, plainspoken, a little wry. Never precious about
  craft, never trying to look more expensive than it is.

## The goal (the scoreboard)
- **Now:** sell through **65%+ of the Nov 1 capsule drop**, reach **6,000 Instagram followers**
  (from 2,600), and get **3 creators/stylists posting organically.**
- **Then:** a repeatable drop cadence and a real creator/wholesale pipeline.
- Judge every recommendation against the current goal, not vanity metrics.

## The plan
- The drop plan lives in `brand/launch-plan.md`.
- Current phase: pre-launch build, counting down to the **Nov 1** drop.

## The constraint (do not forget this)
- The founder works a full-time job alongside this. Plans must fit **a few focused hours a
  week**, not a full-time founder's schedule. Fewer, bigger moves beat busywork.
- **Budget: $650**, spent only behind what's already proven itself organically.

## Working rules (every agent)
- **Be concise.** Answers in chat, not a new `.md` per decision. Persist only genuine living
  references. Docs stay under 1000 words — a 2-minute read.
- Real financials / customer data live in `data/` — local only, never git, never web search.
