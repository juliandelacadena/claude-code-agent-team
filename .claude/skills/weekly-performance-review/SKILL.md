# Weekly performance review

1. Read the latest `data/ad-performance.csv` and any sales figures the founder provides, plus
   `data/inventory.md`.
2. Summarize what's working / not working from the data (label anything that's a hypothesis).
3. Use web search to note one relevant seasonal or apparel trend, with a source.
4. Give 2–3 recommendations, each with a why and a when (dated), respecting production lead
   times.
5. Hand any margin/cash question to Balbus before recommending a spend increase or a
   production order.
