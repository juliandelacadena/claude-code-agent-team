# Ad batch

1. Read `brand/brand-identity.md` and scan `brand/content-library/` for usable assets.
2. Confirm the objective (sales/traffic/awareness), the product, and the rough daily budget.
3. For 2–3 distinct angles, produce: primary text, headline (≤40 characters), description,
   the asset to use, and the format.
4. Add a simple test plan: which creatives to run first, and the metric that picks the winner.
5. Output one copy-paste-ready block per ad. Mark any claim needing a real source as
   `[NEEDS SOURCE]`.
6. Remind the founder these are drafts to review and publish in Meta Ads Manager.
