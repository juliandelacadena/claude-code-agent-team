# Weekly priorities

1. Read `CLAUDE.md`, `brand/launch-plan.md`, and `data/financials.md`.
2. Ask the founder: how many focused hours this week, and what changed since last week.
3. Identify the current phase of the drop plan and its milestone.
4. Produce:
   - **This week's focus** — max 3 items, each tied to the goal, with a time estimate.
   - **Not now** — what to defer or drop.
   - **Today's first action** — one concrete task to start now.
5. If any item needs a specialist, name the agent (oppius, curio, balbus) and offer to run it.
